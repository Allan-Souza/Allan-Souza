# Hi there, I'm Allan Souza 👋

## 👨‍💻 Who am I
I am a Fullstack Developer and Tech Lead based in Brazil. I balance my professional work with my academic journey, where I'm currently wrapping up my studies and Capstone project. Beyond the screen, I'm a calisthenics enthusiast, a guitar player always tweaking my AmpliTube settings for the perfect tone, and a big fan of Tokusatsu (especially Ryukendo!).

## 🚀 What I do
I build robust web applications, heavily utilizing strong MVC architectures. My recent work spans across various domains:
- Leading development and tracking daily progress on scalable platforms like **Hub**.
- Designing the security architecture for an e-commerce project named **Qatu**.
- Developing a comprehensive payment management system for radio advertisement clients.
- Creating interactive experiences like **Battle Tanks**, a multiplayer game built with Angular and Redis.
- Collaborating with awesome teams on software projects like **PS Sports**.
